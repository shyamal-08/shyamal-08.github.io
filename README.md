# Shyamal Hirapara — Personal portfolio

Static portfolio website for GitHub Pages.

## Publish

Repository: `shyamal-08/shyamal-08.github.io`

In Settings → Pages, select **Deploy from a branch**, then **main** and **/(root)**.

Expected URL after successful publication: https://shyamal-08.github.io/

## Edit

Update `index.html` and push to `main`. The site has no build dependencies. `.nojekyll` keeps GitHub Pages from processing it with Jekyll.
